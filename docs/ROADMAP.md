# National-first delivery plan

## Implemented prototype

One canonical pipeline, all three international formats, local storage, a role-constrained selector, explicit preferences, profiles, descriptive uncertainty, a past-only diagnostic and a synthetic interactive preview. The release has functioning scaffolding for league imports and CLI research fantasy scoring, but the next analytical work remains national.

## Next acceptance milestone: one reconciled national study

Fetch and preserve actual international archives. Reconcile innings, match and player totals against an independent authorized scorecard source. Audit completeness and revisions. Import reviewed South African roles and appointment snapshots, then run the fixed national study protocol. Do not call source acquisition accepted solely because an HTTP request returned a ZIP. Do not publish a Bavuma verdict before the comparator definitions and reconciliation pass.

Extend the exercise to every supported country and women’s international cohorts as coverage permits. Introduce verified full-career aggregates through a separate provenance-aware contract only when the historical source is obtained; do not merge aggregate totals with the same delivery totals and double count.

## Player diagnostics

Add source-attributed physical bowling styles and batting hands. Evaluate context-adjusted matchup models with temporal validation and shrinkage, correcting for searches across many matchups. Separate genuine physical style from outcome-derived clusters; fit any learned archetypes on training data only. Do not label aggression, technique or causal vulnerability from dismissal lists.

## Spatial research

Obtain lawful full-delivery tracking coverage and verify its measurement quality. Join it to the existing delivery identity, implement tracking validation and versioned field-legality rules, then assess confounding and overlap. Only after identification and out-of-time evaluation should a field-policy recommendation be considered. This is a separate scientific milestone, not a frontend feature toggle.

## Franchise and fantasy tier

After the national acceptance milestone, reconcile IPL, SA20, BBL and PSL archives. Add actual squads, availability, player credits and a versioned scoring adapter for the chosen fantasy platform. Jointly optimize captain multipliers with team membership where platform rules require it. Never describe the current generic point system as an official one.

## Release / operations

Obtain independent cross-provider review. Validate one authenticated publication route, run CI remotely and test a manual refresh end to end. Add withdrawal reconciliation, conflict handling for metadata snapshots and scale measurements against full archives. A public multi-user deployment requires authentication, isolated writes, job persistence and a separate security review; do not expose the local server directly.
